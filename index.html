🎮 Cómo jugar
1. Selecciona el importe de tu apuesta.
2. Espera a que comience la ronda.
3. El multiplicador comenzará a subir.
4. Retira manualmente o utiliza Auto Cash-out.
5. Si el crash ocurre antes de retirar, la apuesta termina.
📜 Reglas
La apuesta mínima configurada es de 0.30 USDT.
Las apuestas se bloquean cuando comienza la ronda.
Cada ronda tiene un resultado previamente determinado.
El resultado no depende de la cantidad apostada.
Una apuesta solo puede recibir un resultado.

🔐 Transparencia
El resultado de cada ronda se determina independientemente de las acciones individuales del jugador.
El sistema no modifica el crash point en función del importe apostado, ganancias o pérdidas de una persona.
Los créditos utilizados dentro de esta interfaz no representan fondos reales ni constituyen un retiro de criptomonedas.
